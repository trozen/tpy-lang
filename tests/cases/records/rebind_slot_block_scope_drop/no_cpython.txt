A record local first declared inside a block (`if` / loop body) lives in
block-scoped C++ storage, so its LAST value drops at the closing brace
(`drop if-second` before `after block`) where CPython, whose locals are
function-scoped, drops it at function exit. The superseded values drop at the
rebind on both. The block-exit timing is the general block-local storage
rule, not the rebind slot model.
