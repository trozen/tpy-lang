HTTPSConnection driven over a real mbedTLS handshake against an internal
server peer (the public server path load_cert_chain + wrap_socket(server_side=True)) on a socketpair, via the conn._tls injection
seam -- no CPython equivalent (CPython's ssl needs a real server / threads to
handshake here, which the suite avoids). TLS + HTTP framing correctness is
validated by the exec phase, not cpy parity.
